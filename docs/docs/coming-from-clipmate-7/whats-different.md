# What's different or gone since ClipMate 7

## Different

| In ClipMate 7 | Now |
|---------------|-----|
| ClipBar embedded in the taskbar | The ClipBar hotkey shows the ClipMate Classic window |
| Settings in the Windows registry | Settings in a file, `clipmate.toml`, in `%LOCALAPPDATA%\ClipMate` |
| A database made of many `.DAT`, `.IDX` and `.BLB` files | A database is one file, `clipmate.db` |
| A database shared by several users over a network | Each computer has its own databases, and paired [Devices](../devices/index.md) read the ones you share |
| Skins and magnetic window borders | Light and dark themes |
| A license key | No key: ClipMate is free and open source |
| Glue | Called Append. The tray menu shows both names |

## Gone

- News from the update server
- The Vista clipboard notification option, which is no longer needed

## Not available yet

These menu items or settings are there, but do nothing yet:

- **Check Spelling**
- Screen capture, including its two hotkeys
- Text **Shift Left** and **Shift Right**
- The Font/Language settings
