# First-run setup

The first time ClipMate starts, the **ClipMate Setup** window asks where to keep your clips. A database is the single file that holds them.

1. Under **Database Name**, keep **My Clips** or type a name you prefer.
2. Under **Database Location**, keep the suggested place, or click **Browse...** to choose another.
3. Click **Continue**.

ClipMate creates the database and starts capturing what you copy. You can add more databases later in [Database Options](../options/databases.md).

## Finding ClipMate

ClipMate keeps running in the background, with an icon in the system tray next to the clock. Windows may tuck the icon under the arrow that shows hidden icons.

- **Click the icon** to open ClipMate.
- **Right-click the icon** for a menu of common actions, including **Exit Program (Shut Down)**.
- **Press Ctrl+Alt+C** to bring ClipMate up from any program.
