# Install ClipMate

ClipMate runs on Windows 10 version 1809 or later and Windows 11. You don't need administrator rights: it installs for your Windows account only.

## Install with the installer

1. Download `ClipMate-Setup-<version>.exe` from the [Releases page](https://github.com/Tsabo/ClipMate/releases).
2. Run it and follow the steps. The installer also adds the Microsoft components ClipMate needs, if they're missing.
3. To have ClipMate start when you sign in, tick **Start ClipMate when Windows starts**.
4. Leave **Launch ClipMate** ticked on the last step, and finish.

## Install with winget

If you prefer the command line, open Terminal and run:

```powershell
winget install Tsabo.ClipMate
```
