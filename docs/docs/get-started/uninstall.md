# Uninstall ClipMate

1. Right-click the ClipMate icon in the system tray and choose **Exit Program (Shut Down)**.
2. In Windows, open **Settings > Apps > Installed apps**, find **ClipMate**, and choose **Uninstall**.
3. If you turned on networking, ClipMate asks whether to remove the Windows Firewall rule it added. Choose **Yes**, and Windows asks for permission.
4. ClipMate asks whether to delete your clip database and settings as well:
   - Choose **No** to keep them for a future reinstall. This is the default.
   - Choose **Yes** to delete them. You can't get those clips back unless you have a backup.

If you chose a different location for a database, that file stays where it is. Delete it yourself if you no longer want it.
